The current release of ACPICA is version 20260930

- [Introduction to ACPI Architecture](https://cdrdv2.intel.com/v1/dl/getContent/772721)

- [Basic ACPI Source Language (ASL) Constructs Tutorial](https://cdrdv2.intel.com/v1/dl/getContent/772722)

- [ACPI Source Language: ASL 2.0 Introduction and Overview](https://cdrdv2.intel.com/v1/dl/getContent/772723)

- [ACPI Specification Version 6.6 (May 2025)](https://uefi.org/specs/ACPI/6.6/)

- [All ACPI Specifications](https://uefi.org/specifications)

- ACPICA User Guide and Programmer Reference
    - [pdf](https://cdrdv2.intel.com/v1/dl/getContent/772726)
    - [doc](https://cdrdv2.intel.com/v1/dl/getContent/772894)

- iASL: ACPI Source Language Optimizing Compiler/Disassembler User Guide
    - [pdf](https://cdrdv2.intel.com/v1/dl/getContent/772727)
    - [doc](https://cdrdv2.intel.com/v1/dl/getContent/772895)

- [ACPI Specification Version 6.1 (January 2016, 6.2 MB, 1082 Pages)](https://uefi.org/sites/default/files/resources/ACPI_6_1.pdf)

- [Runtime BIOS Fixes for ACPI Tables (July 2013)](https://cdrdv2.intel.com/v1/dl/getContent/772746)
    - Describes methods for the BIOS to perform runtime modifications to ACPI
      tables before handoff to the operating system.

- [Intel® Processor Vendor-Specific ACPI: Interface Specification (December 2014)](https://cdrdv2.intel.com/v1/dl/getContent/772754)
    - Describes the Intel® processor driver capabilities bit definitions.

- [Processor Clocking Control Interface Specification (Version 1.0, February 23, 2009)](https://cdrdv2.intel.com/v1/dl/getContent/772755)
    - Technical description of the Processor Clocking Control (PCC) interface.

- [BIOS Boot Specification (Version 1.01 January 11, 1996)](https://cdrdv2.intel.com/v1/dl/getContent/772756)
    - Technical description of how the BIOS should identify boot devices.

- [Multiprocessor Startup for ARM\* Platforms (Version 1, September 23, 2014)](https://cdrdv2.intel.com/v1/dl/getContent/772757)
    - Protocol for starting multiple ARM\* processors.

- [Core System Resources Table (CSRT November 14, 2011)](https://cdrdv2.intel.com/v1/dl/getContent/772760)
    - Definition of CSRT ACPI table for shared hardware functions.
